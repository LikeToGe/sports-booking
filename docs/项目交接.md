## 项目目标与边界

“约场”当前是郑州市多场馆固定场次预约的本地 Mock MVP。用户使用微信原生小程序找场馆、创建预约、模拟支付并出示核销凭证；平台和场馆使用 Vue 后台运营。

本轮计划将其完善为以羽毛球馆为主场景、底层支持多运动类型的双边平台。核心业务数据、状态机、审计、幂等和异常恢复按可上线标准实现；微信登录、支付/退款、订阅消息、媒体存储和内容检测使用可替换的 Mock 或本地 Adapter。生产部署、真实外部资质与渠道接入仍不在本轮范围。

下文“已实现”只描述当前代码事实；P4 业务闭环和隔离运行态已完成，开发者工具模拟器与物理真机仍未完成，P4 不能标记为最终上线验收通过。

## 已实现的业务闭环

### 身份与权限

- 平台管理员、场馆管理员与小程序用户均可建立 Redis 会话；小程序使用 Mock code 登录。
- 后端从后台或小程序会话推导平台、场馆、用户和员工身份，Controller 不信任客户端传入的归属 ID。
- 用户可绑定一个场馆员工身份；该身份不影响其普通预约能力，并可用于线上预约核销及本场馆会员码/完整手机号识别。

P1 已增加场馆级顾客/会员关系和会员码；P2 已增加充值档位、实付/赠送余额、到期提醒和不可变资金流水。P3 已增加固定权限目录、普通员工多角色权限并集、员工扫码登录 Web 和即时撤权；平台管理员仍只看场馆级会员经营汇总，不查看个人资料或逐笔流水。

### 场馆供给与运营

- 平台可创建、查看、编辑、上架或停用场馆，查看和修改场馆管理员用户名及密码，并创建、编辑、启停平台运动类型。
- 场馆可维护资料、封面、场馆运动类型、场地与员工；场馆运动类型、场地和员工均支持新增与编辑，一个场地可关联多个运动类型，但同一时段只接受一笔预约。
- 场馆可新增、编辑周场次，复制星期模板，生成、临时增加或编辑任意状态的具体场次，关闭整天或单个场次，并重新开启符合条件的已关闭场次；人工编辑后的具体场次不再跟随周场次同步。
- 场馆可创建电话/到店的线下预约、修改任意状态线下预约的联系人，或带原因取消预约；平台和场馆均有经营报表入口。

### 用户预约与履约

- 小程序可按平台运动类型、日期和名称查找场馆，查看场馆、场地和具体场次。
- 用户可填写或复用联系人资料，创建线上预约；创建事务同时占用具体场次、按批次冻结可用余额并固定赠送/实付/单一外部支付组成。
- 全余额预约直接确认且不创建外部支付记录；组合支付在事务和 Redis 锁外发起 Mock 渠道调用，支持成功、失败、未知、查单、超时和重复通知收敛。
- 用户在取消截止前可取消，场馆取消必须填写原因；线上取消按原余额批次返还，外部差额使用稳定退款业务号异步重试。
- 预约详情提供动态二维码与 6 位短码。员工可扫码或输入短码核销，并查看本人核销记录。
- 定时任务每分钟释放超时待支付预约，并将结束后仍未核销的已确认预约标记为未到场；每日按业务时区生成预约窗口内的具体场次。

P1 已将线下预约收敛为只登记和占用场次，以独立登记收款状态记录 `UNRECORDED / UNPAID / PAID / REFUNDED`，不产生平台支付、退款、余额、核销或未到场事实，结束后进入 `ENDED_UNTRACKED`；并支持多日期整批预约与同价改期。

### 状态与一致性

- 预约：`PENDING_PAYMENT -> CONFIRMED -> COMPLETED`，也可进入 `CANCELLED` 或 `NO_SHOW`。
- 具体场次：`OPEN -> HELD -> BOOKED`，也可进入 `CLOSED`；取消或支付超时会按可预约条件释放。
- `s_session_slot(court_id,start_at,end_at)` 唯一键防止精确重复；场地行锁、库存半开区间检查及有效预约快照的锁定当前读共同防止重叠与超卖。
- 预约保留场馆、场地、运动、时间和价格快照，不随资料或周场次修改而变化。
- 具体场次人工编辑不改写已有预约快照；线上预约联系人不允许由场馆后台修改。

P0 已为具体场次和预约敏感写入增加 `sports-booking:lock:` Redis 业务锁；P2 增加 `MEMBER_BALANCE` 和 `RECHARGE` 锁，并按完整 key 排序取得多资源锁。锁覆盖完整数据库事务，外部 Adapter 调用发生在事务和 Redis 锁外；行锁、条件更新、事务和唯一约束仍是最终一致性保障。

### 平台服务费验证

- 平台管理员可为每个场馆配置 `0%～30%`、最多两位小数的服务费率；场馆管理员只读。
- 新线上预约保存服务费率快照，历史和线下预约按 `0%`；调价不追溯已有预约。
- 月度结算只统计已完成或未到场且费率快照大于 `0` 的线上预约，按场次结束月份归集。
- 服务费不舍入或截断，后端以整数微元精确汇总并返回最多六位小数的元金额。
- 平台和场馆复用现有报表页查看汇总与逐笔明细；当前不为平台服务费建立账本、月账单状态机或真实收款链路。
