## 三种设计方向

| 方案 | 视觉 | 管理端结构 | 小程序结构 | 取舍 |
|---|---|---|---|---|
| **A · 清爽运动（推荐）** | 绿白、浅灰绿、少量嫩绿；简洁无衬线字 | 分组侧栏、排场主画布、待办侧栏 | 紧凑搜索、近 7 天日期、统一横排场馆 | 信息清楚，适合高频订场；品牌表现较克制 |
| **B · 活力赛场** | 炭黑、暖白、运动橙；更强的字重与对比 | 顶部导航、宽排场区、深色待办侧栏 | 深色头部、最近可约场馆大图、紧凑次级列表 | 运动感更强；首屏可比较的场馆数量较少 |
| **C · 城市俱乐部** | 暖砂、棕色、奶白；宋体标题配无衬线正文 | 侧栏、当日日程账页、服务待办 | 舒展标题、横幅场馆图片、细线分隔 | 更有场馆氛围；日程视图不如网格适合密集排场 |

## 如何看稿

- 顶部选择 A/B/C；底部箭头或键盘左右键也可切换，URL 保留当前方案与页面。
- “双端对照”用于判断一致性；“管理端”或“小程序”可单独查看。
- 各画板上方下拉框切换页面；管理端侧栏与小程序底栏可以点击。
- 小程序首页可切换运动与日期；场馆页可选择场地、场次并进入确认预约；会员页可选择充值档位。
- 搜索只筛选示例数据，按钮打开的表单与详情属于设计演示。部分次级入口仅说明后续页面，不包含完整业务流程。
- 小程序画板内部可以向下滚动。画板为内容区域，不绘制虚假的手机外壳、系统状态栏或微信胶囊。

## 共同规则

- 管理端面向密集运营，小程序面向单任务与触控，统一品牌与图标语言。
- 预约履约、线上收款和线下人工登记状态分开表达；金额保持业务口径。
- 会员与余额按场馆独立。平台管理端不展示个人资金流水。
- 不加入优惠券、会员等级、推荐榜单、平台钱包、精确距离等现有范围外能力。
- 动态为开启社区功能时的示例；正式实现仍须支持关闭入口。
- 颜色、圆角、排版均是候选方案，不覆盖根目录已锁定的 `design.md` 与 `tokens.css`。
