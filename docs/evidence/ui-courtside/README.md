# 场边工作台生产 UI 实施证据

2026-10-14。按已批准的 `docs/ui-design-courtside/` 实施，生产源码覆盖 **25 个管理端路由、23 个小程序注册页、38 个关键模式/状态**。旧图稿不作为本轮视觉目标。未提交、推送或部署；后端源码与依赖保持不变。

## 改动与边界

- `design.md`、`tokens.css`：同步青绿操作、白色内容、冷灰画布，以及排版、间距、圆角、边界与焦点。
- `admin-web/src/App.vue`、`styles.css` 和全部 21 个视图文件：白色 206px 导航、宽排场、指标分隔、表格、表单、模态和抽屉；登录、资料封面、顾客经营工具、报表趋势与热力图分别调整。公共旧主题叠加规则已整理。
- `miniapp/app.wxss`、新增 `tokens.wxss`、底栏与反馈组件、全部页面 WXML/WXSS：场馆图片比例、信息顺序、表单、任务底部操作、社区媒体与员工工作区。组件显式引入同一组变量，修复底栏不继承 `page` 变量的问题。
- 首页已有时间/价格筛选可以展开并保留条件；五个 Tab 在原生组件就绪后刷新稳定路径选中态。动态/球友页通过既有认证下载工具展示真实图片，下载失败保留正文，旧请求不覆盖新筛选。
- 微信开发者工具编译脚本增加共享 Token 和反馈组件，避免只检查页面而漏掉实际组件。新增最小行为回归；未增加依赖。

完整文件列表见 [changed-files.txt](changed-files.txt)，此列表以任务开始时的工作区为基线。已有用户预约、支付、提醒业务修复与测试保持原样，见 [preservation-check.txt](preservation-check.txt)。API、认证、权限、计价、支付/充值/注销状态、凭证和社区开关继续使用当前实现。

## 图稿与真实规则的差异

- 真实价格按单个完整场次总额展示，保留异长场次、余额实付/赠送组成与实际取消截止；不从示例“每小时”价格推导计费。
- 真实供给中部分预约已超时关闭、招募已取消、评价未获资格；截图保留这些状态与恢复入口。空集合保持空状态，未填入图稿的人名、经营指标或预约记录。
- 真实核销/会员/Web 登录二维码来自现有接口。微信导航、picker 和注销系统确认使用平台原生呈现；确认文案保留完整真实条件。
- 顶栏与入口依据真实登录身份和权限，图稿没有实际接口的营业状态、场馆切换和通知示意不进入生产。

## 未完成的环境验收

窗口控制最后连续返回 `cgWindowNotFound`；应用清单仍显示微信工具运行。CLI 则返回 `IDE service port disabled`，未开启或更改安全设置。原生补拍的具体影响如下：

- 加载过早的五张：320px 支付/提醒、375px 我的、414px Web 登录/核销。这些样本从通过计数中排除。
- 场馆页四尺寸与场次网格截图早于最后将预约说明移至列表后，最终信息顺序需要窗口恢复后补拍；原生编译与场次行为回归已通过。
- 会员识别模式表单已见原生截图，识别结果仍需原生输入点验；隔离识别 API 与既有行为回归通过。
- 支付未知、首页加载/空列表/接口失败尚未取得对应原生模式截图。代码、原生编译与已有相关 Node 分支验证保留，未声称完成原生验收。
- 物理真机、相机扫码、实际微信登录/支付/订阅渠道、真实输入法与辅助阅读仍需补验。当前项目渠道继续是既有 Mock/Adapter。

## 已修正的验证尝试

初跑包括回归等待点过早、编译脚本漏列新引入的共享 WXSS、尺寸标签沿用了旧值、移动排场选择器仍指向隐藏网格，案件夹具的 glob 最初未匹配 evidence 子路径，以及误把原生单按钮 dialog 的浏览器 chrome 焦点暂移当作背景泄漏。分别改用明确等待点、补全编译入口、核对实际设备并重新采集、使用移动列表选择器、修正并断言案件正文夹具实际加载，以及检查反向 Tab 返回和背景阻断，最终管理端与 Node 检查通过。员工测试清理首次误用 PUT，按既有 PATCH 接口修正并复核完成。

以上结果支持源码评审与继续补验，不代表真机或生产渠道发布验收通过。
