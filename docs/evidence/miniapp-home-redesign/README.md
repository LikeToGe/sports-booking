- `zsh miniapp/scripts/verify-native-compile.zsh`：21 个 WXML、22 个 WXSS 原生编译通过。
- `node --test miniapp/tests/*.test.js`：4 个测试文件通过；补充社区开关前后预约、会员、我的图标绑定不变的回归断言。
- 浏览器四档宽度无根级横向溢出，SVG 与场馆图片均加载；主要触控区域宽高均不少于 44px，首家场馆在首屏完整呈现。
- 加载、空列表、错误与重试、长名称及暂无场次、四／五个 Tab 布局检查通过。错误不会同时显示空列表提示。
