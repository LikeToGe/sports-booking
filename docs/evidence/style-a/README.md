# A「清爽运动」落地与验证

2026-10-08。用户从双端设计稿中选择 A 后，将该方向应用到现有管理端与微信原生小程序。

## 改动

- 根 `tokens.css` 与小程序同名变量统一绿白底、森林绿主操作、浅绿选中态和状态语义。
- 管理端采用浅色分组侧栏与轻量表格；今日运营以排场为主、待办为辅，趋势放在下方。小屏排场转为场次列表；表格、抽屉和权限分支沿用原有实现。
- 小程序首页保留真实筛选与跳转，新增近七天快捷日期；窄屏局部横向浏览日期。
- 个人中心改为资料摘要、快捷入口和分组工具，联系人表单按需展开；成功保存后同步摘要，失败时保留表单。
- 会员页突出实付与赠送余额，会员码按需展开；切换场馆时收起上一场馆凭证。
- 预约、详情、支付、确认预约、场馆与动态使用浅色内容表面；动态默认展示列表，发布或编辑时展开编辑器。
- 保留原有接口、权限、资金计算、支付流程和账号注销确认；未修改后端。
