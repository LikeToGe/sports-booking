# 小程序完成反馈与触控动效

2026-10-16。按用户确认的方案实施；保留工作区已有管理端及文档改动，未提交、推送或部署。

## 实现范围

- 公共 `action-feedback`：原生按钮内展示加载指示、完成勾号和状态文案；成功反馈停留 420ms 后通知原页面跳转或收起。页面隐藏／销毁清理计时，返回当前页可恢复完成通知。原有错误与重试入口保留。
- 预约创建、支付／取消、充值、联系人保存、协议接受、提醒登记、评价、动态／评论、员工绑定／登录／核销／充值及收藏接入公共反馈。纯导航和打开系统确认的操作保留原交互。支付／充值仅依据真实服务端终态显示完成，请求成功但支付待确认时不显示成功勾号。
- 公共 `selection-mark`：协议勾选、充值档位和评价标签同步勾号、高亮及按钮可用状态；匿名公开、允许评论、免费／AA 选项显示对应状态。评论开关写入失败恢复原值。
- 公共 `time-wheel`：首页时段筛选和提醒登记使用小时／分钟底部面板，微信原生 `picker-view` 负责惯性减速、停止与刻度吸附；滚动中禁用确认，取消／离开页面不提交草稿。遗留非零秒值在用户取消时原样保留，原有分钟精度、起止时间及跨天校验保留。
- 自定义 Tab：从点击坐标计算覆盖四角的圆，280ms 扩散后切页，目标页接续遮罩并用 160ms 淡出。忽略当前 Tab／不可见社区入口和转场期间重复点击；失败、超时、离开页面解除遮罩和锁。原生顶部导航栏不参与转场。
- 动效保留减少动态样式。没有新增依赖，没有修改后端、HTTP 契约、支付决定权或权限规则。
