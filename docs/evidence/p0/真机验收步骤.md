# 上线前微信小程序真机验收（原 P0 基线）

状态：尚未申请 AppID，暂缓为上线前门禁；不阻塞 P2-P4 开发，未完成时不得将 P1 标记为完全验收通过或允许上线。

目标：在真实手机上完成订场、支付、凭证、取消和员工核销主流程，并保存截图证据。

起点：当前项目使用 `touristappid`，只能在微信开发者工具模拟器中运行。

- [ ] 1. 获取可用于真机预览的小程序测试号 AppID 或自有小程序 AppID。
- [ ] 2. 在微信开发者工具中登录有该 AppID 开发权限的微信号，并导入当前 `miniapp/`。
- [ ] 3. 将小程序 API 地址从 `127.0.0.1` 改为电脑局域网 IP，确认手机与电脑使用同一网络。
- [ ] 4. 使用“真机调试”生成二维码，手机扫码并开启调试模式。
- [ ] 5. 完成订场首页、场馆详情、确认预约、模拟支付、预约详情/凭证、取消和员工核销。
- [ ] 6. 将截图放入 `docs/evidence/p0/miniapp/`，主 Agent 核对后关闭上线前真机门禁。

Notes：

- 真机调试期间可以在手机小程序右上角菜单中开启调试，以跳过本地开发阶段的合法域名校验。
- 不在聊天或仓库中记录微信登录凭据、密钥或其他敏感信息。
